# Devlog: 2026-07-30 (C8.2 Collective Invariants)

## Context

Expanding `test/ext_distributed/common_distributedtest.jl` to strictly prove the underlying collective protocols (bcast!, reduce!, allreduce!) beyond the basic Float64 ones/zeros checks. This is checkpoint C8's collective-invariant block.

## Actions Taken

1. **Rewrote `common_distributedtest.jl`** with five test blocks:
   - **Data Type Coverage Matrix**: loops `bcast!`/`reduce!`/`allreduce!` over `Float32` & `Float64` (`Array`) for MPI, and `Float16` & `Float32` (`CuArray`) for NCCL.
   - **Nonzero Root Broadcast**: `bcast!` with `root=1` (two-buffer + in-place), asserting non-root ranks receive the root's value `7`.
   - **Sum vs. Average Convention**: guarded on `nworkers == 2`; rank 0 = `[2.0]`, rank 1 = `[4.0]`; `allreduce!(..., avg)` → `[3.0]`, `allreduce!(..., +)` → `[6.0]` — independent of `sum(1:nworkers)`.
   - **Buffer Reuse Leakage**: `fill(rank, 4)` → `allreduce!(..., avg)` → mutate same buffer to `fill(rank*2, 4)` → `allreduce!(..., avg)` again; asserts the second result reflects the new values (no stale MPI/NCCL internal buffers).
   - **NCCL vs MPI Math Equivalence** (NCCL only): large `Float32` `CuArray` (N=262144) of rank-dependent noise (`MersenneTwiller(42+rank)`), NCCL `allreduce!(+,)` → copy to CPU, compare against MPI `allreduce!(+,)` via `backend.mpi_backend`; `maximum(abs.(diff)) < 1e-6`.
