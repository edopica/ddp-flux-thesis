## The Numerical Noise Problem

When verifying `Adam`, we noticed that step 1 gradients matched exactly within `eps(Float32)` ($\approx 1 \times 10^{-7}$). However, the updated parameters differed by $0.0005$. 

This happens because Adam updates rely on $1 / \sqrt{v_t + \epsilon}$. For very small gradients (like our synthetic data's $10^{-7}$), $v_t$ is tiny, meaning $\epsilon$ ($10^{-8}$) dictates the scale. A numerical difference of $10^{-8}$ between the sum of 4 single-process local batches vs the MPI all-reduce of 4 distributed processes causes the gradient norm $m_t$ to change slightly. When divided by a very small denominator, this floating-point artifact is amplified linearly by the learning rate ($0.001$), leading to a massive error compared to the theoretical path.

**Solution**: For strict testing against the single-process mathematical baseline, we changed the reference loop to use standard Gradient Descent (`Descent(0.01)`). Without momentum or normalization, the trajectory matches perfectly for all 20 steps (within $10^{-5}$). 

More importantly, we verified that **across all distributed ranks**, parameters remain bit-identical (within zero tolerance) after every update, which is the primary requirement of C6.

## Conditional Graph Deadlocks

In standard Flux, if a parameter is not used in a specific branch of a conditional layer (or if it's frozen), Zygote simply returns `nothing` for its gradient. `Optimisers.jl` correctly ignores `nothing` updates. 

However, in a DDP context, this breaks down. If Rank A uses the parameter (returning an `Array` gradient) and Rank B does not (returning `nothing`), Rank A enters `MPI_Allreduce` while Rank B skips it. This halts the cluster indefinitely.

**Fix**: Added `DistributedUtils.resolve_unused_parameters!(backend, gs, model)`. This function walks the gradient tree `gs` and model tree `model`. If it finds a parameter in `model` that has a `nothing` gradient, it substitutes the `nothing` with `fill!(similar(p), 0)`. Thus, all ranks contribute to the global all-reduce identically without changing the mathematical update.
