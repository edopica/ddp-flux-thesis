## Review findings (M1 gate reopen, 2026-09-08)

Blocking (7):

1. Trainable-semantics mismatch: sync traversal did not mirror `Optimisers.setup`
   (BatchNorm `μ`/`σ²` would be treated as trainable).
2. `update!` discarded the model returned by the inner update (immutable components lost).
3. KeyPath replay of gradients failed for `Transpose`/`Adjoint` leaves.
4. Absent-vs-zero gradient semantics wrong: globally-absent parameters must skip the
   optimizer step (Adam state untouched), while locally-missing-but-globally-present
   parameters must contribute zero.
5. Composition silently disabled sync: nesting `DistributedOptimizer` inside another rule
   (or vice versa) synced nothing without error.
6. Out-of-place update mutated caller-provided gradients.
7. `collect(g)` was not device-preserving.

Additional risks: isbits param tie dedup via `objectid`; higher-order (`higher...`) grads
forwarded unsynced; Enzyme `Duplicated`/`Chain` ambiguities; legacy
`resolve_unused_parameters!!`.

Test-proof gaps: conditional test used manual gradients instead of real AD; no analytic
4-rank weighting check; no Adam-vs-reference comparison; the "4-rank" evidence was actually
duplicated 4-rank children under `make c8-mpi` (both ranks ran the same 4-rank child
suite).

## Fixes (commit `3370b910`)

1. **Trainable-semantics traversal:** `_sync_gradients` walks the model through
   `Optimisers.trainable`, stopping at `Optimisers.isnumeric` leaves — exactly mirroring
   `Optimisers.setup` (BatchNorm `μ`/`σ²` excluded; proven by CountingBackend test).
2. **`Optimisers.update!`** now propagates the model2 returned by the inner update
   (immutable components).
3. **Structural gradient pairing** via `Functors.functor(typeof(model_node),
   base(grad_node))[1]` (same alignment as Optimisers itself); no KeyPath replay;
   `Transpose`/`Adjoint` get parent-space gradients (matrix and row-vector cases tested
   analytically).
4. **Presence protocol:** one Float32 `avg` allreduce of 0/1 flags per step (works on MPI
   and NCCL; threshold `> 0`, not `> 0.5`); locally-missing-but-globally-present → zero
   contribution; globally-absent → `ZeroTangent` so the optimizer step is skipped (Adam
   state untouched — tested).
5. **Composition rejected explicitly:** `Optimisers.init`/`apply!` on
   `DistributedOptimizer` throw `ArgumentError` (top-level setup goes through the
   specialized method, so `init` is only reachable when nested).
6. **Caller gradients never mutated:** every grad is copied into a fresh `similar(p)`
   buffer before accumulation/allreduce (fixes both update and update!).
7. **Device-preserving buffers:** `similar(p)` + `copyto!`; `collect(g)` removed.

Extras:

- Higher-order `higher...` grads rejected with `ArgumentError`.
- Enzyme `Duplicated` setup unwraps `model.val`; Duplicated update rejected.
- Chain-tuple diagnostic mirrored (ambiguity with Flux basic.jl resolved).
- Rule-level adjust moved to public `Optimisers.adjust` (private `_adjust` method removed).
- `Functors.@functor DistributedOptimizerState (tree,)`.
- `resolve_unused_parameters!!` and `unused_parameters_distributedtest.jl` deleted
  (automatic path supersedes; PR not shipped upstream).
- `Test.detect_ambiguities(DistributedUtils; recursive=false)` → 0.
