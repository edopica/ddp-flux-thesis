# 2026-07-22: C7 - End-to-end examples

## Summary

Executed C7 plan: Created a robust end-to-end distributed training example and integrated it into the upstream documentation.

## Details

### Example Script (`scripts/examples/train_ddp.jl`)
- Written to support both MPI (CPU) and NCCL (GPU) conditionally via `CUDA.functional()`.
- Implements a `TwoHeadModel` with conditional graph execution (Rank 0 uses `head_a`, Rank 1+ uses `head_b`).
- Explicitly demonstrates how to handle unused parameters via `DistributedUtils.resolve_unused_parameters!!`.
- Utilizes `DistributedDataContainer`, `DistributedOptimizer`, and model `synchronize!!`.

### Validation
- **Local**: Tested with `make example-ddp` (failed initially due to API change from `!` to `!!` in `resolve_unused_parameters!!`, fixed).
- **HPC**: Precompiled environment via `scripts/remote/precompile.sh hpc`.
- **HPC Execution**: Ran `NTASKS=2 ./scripts/remote/run.sh hpc make example-ddp`.
- **Result**: Output confirmed clean execution with loss converging from 0.2019 down to 0.0924 across 5 epochs.

### Documentation (`ddp_flux/docs`)

- Contains snippets broken down step-by-step covering Initialization, Sharding Data, Model/Optimizer Sync, the Training Loop, and Conditional Graphs.
- Registered under the "Guide" section in `docs/make.jl`.
